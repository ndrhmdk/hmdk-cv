## **Featured Projects**

### **1. Multimodal Skin Lesion Assistant**

**Computer Vision · Retrieval-Augmented Generation**

A multimodal medical assistant combining a Vision Transformer classifier with Retrieval-Augmented Generation for skin-lesion classification.

The system includes:

- Vision Transformer classification
- Retrieval-Augmented Generation
- FastAPI backend
- Streamlit interface
- PyTorch-based deep learning pipeline

**Technologies**

`PyTorch` `ViT` `RAG` `FastAPI` `Streamlit`

[View Project on GitHub →](https://github.com/ndrhmdk/multimodal-skin-lesion)

---

### **2. Moirai Time-Series Forecasting**

**Time-Series Forecasting · Benchmarking**

An end-to-end benchmarking project evaluating the **Moirai foundation model** against statistical and machine-learning baselines.

The project evaluates zero-shot and few-shot forecasting across financial and environmental datasets.

**Technologies**

`Python` `Moirai` `Statsmodels` `Scikit-learn`

[View Project on GitHub →](https://github.com/ndrhmdk/foundation-moirai-time-series-forecasting)

---

### **3. LTSF-Linear Reproduction**

**Paper Reproduction · Time-Series Forecasting**

A from-scratch reproduction of:

> *Are Transformers Effective for Time Series Forecasting?*

The implementation includes the major LTSF-Linear model variants:

- Linear
- NLinear
- DLinear

It also includes the ETTh1 dataset pipeline and an experiment runner for comparing results with the original paper.

**Technologies**

`PyTorch` `NumPy` `Pandas`

[View More Projects on GitHub →](https://github.com/ndrhmdk)

---

### **4. Deepfake Detection System**

**Deep Learning · Explainable AI**

An image and video deepfake-detection pipeline using several CNN architectures:

- ResNet18
- Xception
- EfficientNet

The project also uses **Grad-CAM** to provide visual explanations of model predictions and includes a Streamlit demonstration interface.

**Technologies**

`PyTorch` `CNNs` `Grad-CAM` `Streamlit`

[View Project on GitHub →](https://github.com/ndrhmdk/deepfake-detection)
